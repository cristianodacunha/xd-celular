# XD Celular

Pacote publicado do PWA XD Celular, espelhado do beta da Hostinger.

## Estrutura

- `assets/`: imagens, icones e video do menu.
- `catalogo-xd/`: PWA do catalogo, dados offline, miniaturas, fontes e bibliotecas.

Este repositorio contem somente os arquivos ativos de publicacao. Backups e logs locais nao fazem parte dele.

## Publicacao

O PWA continua servido pelo Hostinger em HTTPS. Este repositorio e uma fonte versionada dos arquivos e pode hospedar ativos publicos se os links do aplicativo forem alterados para esse destino.

Nao armazene credenciais, banco de dados ou arquivos privados neste repositorio.
